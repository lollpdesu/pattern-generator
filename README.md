# Pattern Generator

A single-file browser app for designing vector patterns and exporting them as SVG or PNG. Open `index.html` in any modern browser; no install or internet connection needed.

## Patterns

Voronoi · Delaunay · Polygon · Hexagon · Squares (straight or 45° diamonds) · Brick · Random tiles · Dots · Curved triangles · Flower · Interlaced arcs · Al Bahar "breathing" façade

## Features

- Seamless tiling on X, Y or both, with a tile preview
- Exact sizes in px, mm, cm or m, with the cylinder diameter / radius shown for wrapping round objects
- Single regular polygon sized by side length, inner or outer radius, with construction circles
- Gap, rounded corners, holes, rotation and stretch controls
- Fill with palettes, gradients and variation; optional strokes and edges
- SVG export (Inkscape layers, real-world units) and PNG export
- Presets, undo / redo, projects saved as JSON
